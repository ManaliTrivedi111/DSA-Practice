# 1872. Stone Game VIII

# Problem Summary:

Alice and Bob take turns playing a game with an array of stones. Alice goes first. On each turn, a player must take the first x stones, where x is at least 2, and add their values to their score. The game continues until all stones have been taken.

The goal is to determine the maximum score difference Alice can achieve over Bob, assuming both players play optimally.

# Approach Used:

The solution uses dynamic programming together with prefix sums.

First, the input array is cloned into the prefix array, and the array is converted into a prefix-sum array. This allows us to calculate the sum of any prefix in O(1) time.

The DP array stores the best score difference that the current player can achieve from each state. At every state, the current player has two choices: keep the result from the next state, or take the current prefix and then account for the opponent's optimal result from the next state.

The recurrence is, dp[i] = max(dp[i + 1], prefix[i + 1] - dp[i + 1])
The base case is, dp[n - 2] = prefix[n - 1], because when only the final possible move remains, the current player takes all remaining stones.

# Steps:

1. Store the length of the array in n.
2. Clone stones into prefix so that the original array is not modified.
3. Create a dp array of size n and initialize it with Integer.MIN_VALUE.
4. Convert prefix into a prefix-sum array.
5. Set the base case dp[n - 2] to the total sum of all stones.
6. Traverse the DP array from right to left.
7. For each index, choose the better of:
   * dp[i + 1], representing the result from the next state.
   * prefix[i + 1] - dp[i + 1], representing taking the current prefix and then accounting for the opponent's optimal result.
8. Return dp[0], which represents the maximum score difference Alice can achieve.

# Solution:

```
class Solution {
    public int stoneGameVIII(int[] stones) {
        final int n = stones.length;                                         // T(n) = O(1), S(n) = O(1)
        int[] prefix = stones.clone();                                       // T(n) = O(n), S(n) = O(n)
        int[] dp = new int[n];                                               // T(n) = O(n), S(n) = O(n)
        Arrays.fill(dp, Integer.MIN_VALUE);                                  // T(n) = O(n), S(n) = O(1)

        for(int i = 1; i < prefix.length; i++) {                             // T(n) = O(n)
            prefix[i] += prefix[i - 1];                                      // T(n) = O(1) per iteration
        }
        dp[n - 2] = prefix[n - 1];                                           // T(n) = O(1)

        for(int i = n - 3; i >= 0; i--) {                                    // T(n) = O(n)
            dp[i] = Math.max(dp[i + 1], prefix[i + 1] - dp[i + 1]);          // T(n) = O(1) per iteration
        }
        return dp[0];                                                        // T(n) = O(1)
    }
}
```

# Time Complexity:
T(n) = O(n)

# Space Complexity:
S(n) = O(n)
